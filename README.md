# Shoplet

Monorepo with two apps:

| Folder      | Stack                  | Run                                   |
| ----------- | ---------------------- | ------------------------------------- |
| `backend/`  | NestJS + TypeScript    | `cd backend && npm i && npm run start:dev` |
| `frontend/` | React + Vite + TS      | `cd frontend && npm i && npm run dev`      |
